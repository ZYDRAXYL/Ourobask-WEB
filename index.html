ความสามารถ

ทุกอย่างที่ต้องจำ อยู่ในแอปเดียว

Ourobask ไม่ได้เป็นแค่ to-do list — มันรวมงานที่มีกำหนดส่ง โปรเจกต์ที่ต้องดูภาพรวม กิจวัตรที่ทำซ้ำ ไอเดียที่ยังไม่พร้อมลงมือ และแผนเก็บเงิน เข้าไว้ในโครงเดียวกัน

งานที่ยืดหยุ่นเหมือนโน้ต

ใส่แค่ชื่อเรื่องก็พอ วันและเวลาเป็นทางเลือกทั้งคู่ ไม่ต้องฝืนกรอกให้ครบ

  • ไม่ระบุวัน → เป็นงานไม่มีกำหนดส่ง
  • ระบุวันไม่ระบุเวลา → นับเป็นงานทั้งวัน
  • เลือกระดับความสำคัญและสีได้

ติ๊กเสร็จแล้วหายไปจริง ๆ

งานที่ทำเสร็จจะหายจากทุกรายการทันที แล้วไปรวมอยู่ในหน้าประวัติที่เดียว

  • จัดกลุ่มตามวันที่ทำเสร็จ พร้อมเวลาที่ติ๊ก
  • กู้คืนงานกลับมาทำต่อได้ พร้อมตั้งเตือนใหม่ให้
  • เก็บไว้ 30 วันแล้วล้างอัตโนมัติ

กล่องไอเดียที่หย่อนได้ไม่ต้องเปิด

คิดอะไรออกก็หย่อนลงกล่องได้เลย ของข้างในจะไม่โผล่มากวนจนกว่าคุณจะพร้อมเปิด

  • ปุ่มสุ่มไอเดียหยิบมาทีละใบ ไม่ซ้ำใบเดิมติดกัน
  • เลือกหลายใบพร้อมกันเพื่อแปลงเป็นงาน
  • เปลี่ยนเป็นโน้ตในโฟลเดอร์โปรเจกต์ก็ได้

เควสเก็บเงินที่เห็นความคืบหน้า

ตั้งเป้าหมายเป็นจำนวนเงิน แล้วทยอยหยอดทีละครั้ง เห็นแถบความคืบหน้าทุกที่

  • เก็บครบเป้า เควสถูกทำเครื่องหมายเสร็จให้เอง
  • โฟลเดอร์และหน้าแรกรวมยอดของทุกเควสให้
  • เก็บประวัติการหยอดเงินพร้อมบันทึกช่วยจำ

เตือนล่วงหน้า หรือปลุกให้ตื่น

ตั้งเตือนได้หลายรายการต่อหนึ่งงาน แต่ละรายการเลือกได้ว่าจะเตือนเบา ๆ หรือปลุกเต็มเสียง

  • เลือกจาก dropdown เช่น ก่อน 1 ชม. / 1 วัน / 1 สัปดาห์
  • ปลุกใช้เสียงในระบบหรือไฟล์เสียงในเครื่องก็ได้
  • ปิด–เปิดการเตือนได้จากหน้าแรก โดยไม่ต้องลบทิ้ง

โฟลเดอร์โปรเจกต์พร้อมโน้ต

ครอบงานเป็นโปรเจกต์ เลือกไอคอนและสี เห็นความคืบหน้าและยอดเงินรวมในการ์ดเดียว

  • เก็บงาน กิจวัตร และโน้ตของโปรเจกต์ไว้หน้าเดียวกัน
  • ปักหมุดโน้ตสำคัญให้ลอยอยู่บนสุด
  • ลบโฟลเดอร์ได้ทั้งแบบเก็บงานไว้หรือลบไปด้วย

รู้ว่าอะไรใกล้ถึงกำหนด โดยไม่ต้องเรียงเอง

  • กล่องรวมการแจ้งเตือนและปลุก อยู่บนสุด เปิด–ปิดทีละรายการได้จากตรงนั้นเลย
  • สวิตช์บนรายการงาน คุมการเตือนทุกรายการของงานนั้นพร้อมกัน ไม่ต้องเข้าไปในหน้างาน
  • งานที่ไม่มีกำหนดส่งและกิจวัตร อยู่ท้ายสุด ไม่มาแย่งที่งานเร่งด่วน

เควสเก็บเงิน

เป้าหมายเก็บเงิน ที่ทำงานเหมือนงานหนึ่งชิ้น

เควสคืองานอีกประเภทที่ต้องระบุจำนวนเงินเป้าหมาย แล้วทยอยหยอดเงินเข้าไปทีละครั้ง (ถอนออกก็ได้) ผูกกับกิจวัตรได้ด้วย — ระบุยอดต่อรอบ ถึงวันแล้วแอปจะเตือน และกดบันทึกเงินเข้าเควสได้จากรายการกิจวัตรเลย พร้อมประเมินว่าจะครบเป้าในอีกกี่เดือน

  • แถบความคืบหน้าอยู่บนรายการงาน เห็นยอดเก็บได้ / เป้าหมาย และเปอร์เซ็นต์
  • โฟลเดอร์งานรวมยอดของทุกเควสข้างในให้ และหน้าแรกรวมยอดทั้งแอป
  • เก็บครบเป้าเมื่อไหร่ ทำเครื่องหมายเสร็จให้เอง — ลบรายการเงินออกก็ย้อนกลับให้

หย่อนไอเดียทิ้งไว้ก่อน ค่อยกลับมาเปิด

ตอนกล่องปิดอยู่ ปุ่ม หย่อนไอเดีย จะอยู่กลางจอ เขียนอะไรลงไปก็ได้โดยไม่ต้องเห็นของที่อยู่ข้างใน — ไม่มีกองงานค้างมาให้รู้สึกผิด พอพร้อมแล้วค่อยกดเปิดกล่อง เลือกทีละหลายใบเพื่อย้ายไปเป็นงานพร้อมโฟลเดอร์และกำหนดส่ง

  • ปุ่มสุ่มไอเดีย หยิบขึ้นมาหนึ่งใบจากกองทั้งหมด กดได้ทั้งตอนกล่องเปิดและปิด และจะไม่ได้ใบเดิมซ้ำติดกัน
  • ใบที่สุ่มได้เปิดในแผ่นอ่านอย่างเดียว เลือกได้ว่าจะเก็บกลับเข้ากล่อง หรือสร้างเป็นงาน/โน้ต

อยู่ในเครื่องคุณ และย้ายออกได้เสมอ

Ourobask ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ และไม่เก็บสถิติการใช้งาน ทุกอย่างเก็บด้วย SQLite ในเครื่อง ใช้งานได้เต็มรูปแบบแม้ไม่ต่ออินเทอร์เน็ต

ออฟไลน์เต็มรูปแบบ

ทุกฟีเจอร์ทำงานได้โดยไม่ต้องต่อเน็ต สิทธิ์ INTERNET ถูกใช้อย่างเดียวเพื่อตรวจและดาวน์โหลดรีลีสใหม่จาก GitHub เท่านั้น

Export / Import เป็น JSON

สำรองข้อมูลเป็นไฟล์ JSON เก็บไว้เองหรือแชร์ไปแอปอื่น ตอนนำเข้าเลือกได้ว่าจะ รวม กับของเดิมหรือ เขียนทับ แล้วแอปจะตั้งการเตือนใหม่ให้อัตโนมัติ

อัปเดตในแอปได้เลย

ตรวจรีลีสใหม่จาก GitHub Releases โดยตรง ดาวน์โหลด APK ที่ตรงกับสถาปัตยกรรมเครื่องพร้อมแถบความคืบหน้า แล้วส่งให้ตัวติดตั้งของ Android ต่อในแอปเลย

ไฟล์สำรองเวอร์ชันปัจจุบันเป็น format v3 ซึ่งรวมโน้ตของโฟลเดอร์งานไว้ด้วย ไฟล์เก่า (v1/v2) ยังนำเข้าได้ตามปกติ และฐานข้อมูลเดิมจะถูกอัปเกรดให้เองเมื่อเปิดแอปเวอร์ชันใหม่

ตอนนี้เผยแพร่เฉพาะ Android เท่านั้น ตัวแอปเขียนด้วย Flutter และมีโค้ดฝั่ง iOS อยู่ในโปรเจกต์ แต่ยังไม่มีรีลีสอย่างเป็นทางการ เพราะฟีเจอร์ปลุกและติดตั้งอัปเดตในแอปพึ่งความสามารถเฉพาะของ Android อยู่มาก
ข้อมูลซิงก์ข้ามเครื่องได้ไหม
ไม่มีการซิงก์อัตโนมัติ เพราะแอปไม่มีเซิร์ฟเวอร์และไม่มีบัญชีผู้ใช้ ถ้าจะย้ายเครื่อง ให้ Export เป็นไฟล์ JSON จากเครื่องเดิม แล้ว Import บนเครื่องใหม่ โดยเลือกได้ว่าจะรวมข้อมูลหรือเขียนทับ
ทำไมงานที่ติ๊กเสร็จแล้วถึงหายไปหมด
ตั้งใจให้เป็นแบบนั้น — งานที่เสร็จแล้วจะไม่แสดงในหน้าแรก ปฏิทิน หรือโฟลเดอร์งานอีก เพื่อให้รายการเหลือแต่สิ่งที่ยังต้องทำจริง ๆ งานที่เสร็จไปอยู่ในหน้า ประวัติ (ไอคอนนาฬิกาย้อนกลับบนแถบด้านบนของหน้าแรก) จัดกลุ่มตามวันที่ทำเสร็จ กู้คืนกลับมาทำต่อได้ และจะถูกล้างอัตโนมัติหลังครบ 30 วัน ถ้าติ๊กพลาด กด "เลิกทำ" บนแถบข้อความที่ขึ้นมาได้ทันที
การปลุกใช้เสียงอะไรได้บ้าง
เลือกได้สองทาง — เสียงมาตรฐานของระบบ Android หรือไฟล์เสียงในเครื่องของคุณเอง ไฟล์ที่เลือกจะถูกคัดลอกเข้าโฟลเดอร์ของแอป และแปลงเป็น content:// ผ่าน FileProvider เพื่อให้ระบบแจ้งเตือนอ่านได้ ลองฟังก่อนใช้จริงได้ด้วย โดยเล่นที่ระดับเสียงของ alarm
การเตือนไม่ขึ้น ต้องตั้งค่าอะไรเพิ่ม
ตรวจว่าอนุญาตสิทธิ์ POST_NOTIFICATIONS และ "การปลุกและการเตือนที่แม่นยำ" (SCHEDULE_EXACT_ALARM) ให้แอปแล้ว และปิดการประหยัดแบตเตอรี่แบบเข้มงวดสำหรับ Ourobask เพราะผู้ผลิตบางรายจะหยุดงานที่ตั้งเวลาไว้ของแอปที่อยู่เบื้องหลัง
โน้ตกับไอเดียต่างกันยังไง
ไอเดีย อยู่ในกล่องไอเดีย เป็นของที่ยังไม่ผูกกับอะไร หยิบมาสุ่มหรือแปลงเป็นงานทีหลังได้ ส่วน โน้ต อยู่ในโฟลเดอร์งานเท่านั้น ใช้เก็บสรุปประชุม ลิงก์ หรือสิ่งที่ต้องจำของโปรเจกต์นั้น และจะไม่โผล่ที่หน้าแรก ปฏิทิน หรือหน้ารายการงาน — ลบโฟลเดอร์แล้วโน้ตข้างในหายตามไปด้วยเสมอ
โปรเจกต์นี้เปิดให้ร่วมพัฒนาไหม
ได้เลย ซอร์สโค้ดของแอปอยู่ที่ LDKTC/App-Ourobask และของเว็บนี้อยู่ที่ LDKTC/Web-Ourobask เปิด issue หรือส่ง pull request ได้ตามสะดวก
